# ecotech_poos

Este proyecto se trata sobre las actividades en clase que se realizan en POOS, su objetivo principal es documentar el progreso y las actividades realizadas en el mismo modulo

## Requisitos previos

* Python 3.12 instalado en tu equipo.
* Visual Studio Code.

## Instalación y Configuración

1. Clonar el repositorio:
bash
git clone <url-del-repositorio>
cd <nombre-del-repositorio>


2. Crear y activar el entorno virtual:
En Windows:
bash
python -m venv .venv
.venv\Scripts\activate


En macOS / Linux:
bash
python3 -m venv .venv
source .venv/bin/activate


3. Configurar las variables de entorno:
Duplica el archivo de ejemplo o crea un archivo llamado `.env` en la raíz del proyecto.
Completa los valores requeridos (por ejemplo, claves API o credenciales).



## Ejecución

Para ejecutar el proyecto, asegúrate de tener el entorno virtual activado y corre:

bash
python main.py
